Three potential directions for Nexsyis.

01 · Command Center

Command Center

Why: Make the shop feel like a modern ops console — fast status, clear actions, data up front.

Inspired by: Vehicle infotainment / tech dashboards (instrument clusters, icon launchers).

Solid lighter blue, light 1px borders, teal actives, Plus Jakarta Sans, denser spacing, rounded panels.

02 · Drafting Table

Drafting Table

Why: Lean into brand words — grids, blueprints, plans — so the UI feels precise and trustworthy.

Inspired by: Engineering drawings and light-mode blueprint sheets (not dark blueprint cliché).

Dot grid, hairline navy/lavender borders, square corners, corner ticks, IBM Plex.

03 · Minimalist

Minimalist

Why: Reduce noise for all-day use — calm hierarchy, fewer competing chrome treatments.

Inspired by: Quiet SaaS sidebars and airy productivity tools (icon rail, generous whitespace).

Whitespace, lavender rules, navy headers, zebra rows, hover-expand nav, Manrope.
